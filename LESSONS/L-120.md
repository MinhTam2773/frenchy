- `L-120 · 2026-10-18 · security · T-29` — **The Cloudflare Vite plugin writes the local secrets into `dist/<worker>/.dev.vars` on every `vite build` (so `vite preview` has them), taken from `.dev.vars`, else `.env` / `.env.local`, else all of `process.env` when `CLOUDFLARE_INCLUDE_PROCESS_ENV=true`. A gitignored `dist/` hid it (G-72).** → A build folder isn't secret-free by default: `npm run check:dist` (in `npm run check`, and in CI after a build with a canary `.dev.vars`) fails on any env file or local secret value in `dist/`, and `vite preview` reads the root `.dev.vars` through `process.env`. Never upload `dist/` as an artifact.
